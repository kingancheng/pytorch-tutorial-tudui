## 项目说明
本项目整理自B站 [我是土堆](https://space.bilibili.com/203989554) 的 PyTorch 教程（[视频地址](https://www.bilibili.com/video/BV1hE411t7RN)）。项目代码在原教程代码的基础上，经过排序、简化与重写，相当于复盘笔记。


## 教程内容
教程以 **数据加载、卷积神经网络（CNN）基本组件（卷积/池化/线性层）、损失函数与优化器、模型保存加载、tensorboard 可视化** 为知识主线，并使用 CNN 在 CIFAR-10 数据集上的图片分类训练作为完整案例，快速入门 PyTorch 的使用。
